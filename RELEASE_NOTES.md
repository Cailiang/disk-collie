## 1.0.31 更新 / What's new

- 新增“启动项优化”：查看应用的全部启动配置，筛选已启用、已禁用及残留项，展开来源与路径，启停或移除可处理的启动配置。
- 覆盖三平台原生启动来源，明确标记系统管理、权限不足与未知状态；操作前复核、操作后核验，保留程序文件与本地操作记录。
- Add Startup optimization with grouped entries, status/leftover filters, source details, supported enable/disable and registration-only removal.
- Scan native startup sources across platforms, retain protected/unknown/access-limited states, verify changes, preserve application files and keep local operation history.
