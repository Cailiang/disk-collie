# Browser-demo application marks

Production application management reads installed application logos through the OS. These bundled marks are used only by the explicitly labeled browser demo.

- `demo-vscode.ico`: Visual Studio Code site favicon, retrieved from <https://code.visualstudio.com/favicon.ico>.
- `demo-figma.svg`: vector rendering of the Figma mark for its named demo application.

The product marks belong to their respective owners and do not imply affiliation. No MangoDisk assets are bundled.

`mascot/` contains the canonical SVG line-art DiskCollie border collie face. They are production branding, independent of the demo application logos. Source ownership, exports and story timing are recorded in `docs/MASCOT_ASSETS.md`.
